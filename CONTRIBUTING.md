# Contributing to hHolograms

Thank you for contributing.

## Development
- Java 21+ required.
- Build with `mvn clean package`.
- Run tests with `mvn test`.

## Pull requests
- Keep changes focused and documented.
- Add tests for new logic when appropriate.
- Ensure the project builds before submitting.

## Code style
- Follow existing package structure and naming.
- Keep version-specific code isolated in version modules.
